# 🐱 PickScribe 新版本发布：起始页磁贴可自由排序 · 设置页重做 🚀

🗓️ **26-10-23 SP1**

## ✨ 更新要点

本轮更新的重点是**起始页的可配置化** 🧱：哪些磁贴显示、以什么顺序排列，现在都能自己定。设置页也按功能重新分区，常用项更好找 ⚙️

- **起始页**：磁贴可以勾选启用，也能拖动调整顺序 🧩
- **内容区**：标签页可以启用、排序，默认打开项也能指定 🗂️
- **设置页**：按起始页、收藏夹、AI 功能和关于重新分成四块 🛠️
- **默认状态**：起始页改为 **默认关闭**，需要时在设置里打开 👀

> 从 v3.0 直接上来的话，3.1 的「AI 总结 + 追问」和 3.3 的「AI 回帖」也都在这一版里。

---

## 🧱 起始页：磁贴与内容区都能改

起始页保留 Windows 8 的磁贴风格，但布局交给你：

**磁贴**

- 设置页里**勾选**要显示的磁贴，用 **↑ ↓** 调整顺序
- 也可以**直接在起始页拖动**排序，松手即保存 🖱️
- 默认顺序调整为 **「发帖」在最前、「返回社区」在最后**；只有没手动改过顺序的老配置才会迁移 ✅

**内容区**

- 三个标签页（社区精选、我的收藏、快捷导航）都能**启用和排序**
- 「默认打开」可指定，启用项变化时会**自动校正**，不会指向已关闭的标签 🔧
- **搜索框、时钟、底栏**分别提供显隐开关 🔍

**外观**

- 磁贴改为**纯色**，去掉渐变与高光层，与站点原生的**设计令牌**保持一致 🎨
- 右上角换成**头像 + 昵称**胶囊；窄屏（≤620px）只保留头像 👤

**默认状态**

- 起始页改为**默认关闭**。想用的话，在设置页「起始页浮层」打开即可，老用户已开启的状态不受影响 🔘
- 不喜欢还能点「**恢复默认布局**」，一键回到初始配置 ♻️

> 拖拽排序基于 **HTML5 拖放**，移动端体验一般，因此窄屏下保留了设置页的 **↑ ↓** 按钮作为替代方案。

## ⚙️ 设置页重做：按功能分成四区

原来的长表单拆成了**左侧分区导航 + 右侧卡片**：

| 分区 | 主要内容 |
| --- | --- |
| 🧱 起始页浮层 | 显示开关、默认标签、搜索框、时钟、底栏、磁贴与标签页配置 |
| 🗂️ 收藏夹 Plus | 收藏行为、取消收藏处理、同步频率、默认视图、主题、站点注入、数据迁移 |
| 🤖 AI 功能 | 模型与连接、生成参数、提示词与输出、行为、AI 数据 |
| 📄 关于 | LOGO、版本号、功能简介、仓库与反馈入口 |

- 起始页与收藏夹的设置**改动即时生效**，不需要点保存 ⚡
- 左侧导航支持**滚动高亮**与**点击切换**；滚到底部时，最后两个分区也能正确选中 🧭
- 主题可以跟随系统，也可以固定为亮色或暗色；加载前先定主题，**不闪白** 🌗

## ✍️ AI 回帖助手：只填草稿，不替你发送

帖子详情页的回复框工具栏里，有一个「**AI**」入口，面板内再切换「帮我写 / 润色草稿」：

- **帮我写**：读取**标题、正文与已有评论**，生成可直接发布的回复
- 语气可以选赞同、提问、补充、专业或轻松；长度分三档，从 40 字内到 300 字
- **润色草稿**按用途分成三组，分别管表达、语气和结构
- 结果只会填进回复框，也可以复制或让它重写，**不会自动发送** 🛑
- 兼容站点的 `textarea` 与 `contenteditable` 两种回复框

---

## 🪄 AI 写作助手：快捷指令重新分组

- 8 个按钮按用途分组，**左列固定标签，右侧放胶囊按钮**，多行也能对齐
- 分成改表达、理结构、换语言和接着写四组 📚
- 底部可输入自定义要求，`Ctrl + 回车` 直接生成 ⌨️

---

## 🔎 AI 总结面板：三种显示尺寸

默认宽度限制在 `760px`，宽屏下不会横跨整行。需要时可以把面板加宽到正文宽度，或者切到全屏浮层；全屏支持 `Esc` 和点击遮罩退出，退出后会回到原位 🖥️ 窄屏（≤820px）自动铺满，全屏时会锁住页面滚动 🔒

---

## 🗂️ 收藏夹 Plus：数据搬得走

- 可以导出完整备份、表格和 Markdown 清单三种格式，日常备份和整理都够用 📦
- **导入合并**完成后提示「新增 X 条、更新 Y 条」，不做无脑覆盖 🔀
- 支持**清空本地收藏**与**本地统计**
- 站点收藏夹仍是唯一数据来源，插件只在本地附加**分组、标签和备注** 🏷️

## 📌 打包与分发

- 本次发版 **3.4.0**，继续采用**单体套件**：一个扩展装下「编辑器 + AI 助手 + 回帖助手 + 起始页 + 收藏夹」，**每项功能单独开关** 🧩
