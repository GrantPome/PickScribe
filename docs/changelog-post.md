# 🐱 PickScribe 更新记录 · 2026-10-23 🚀

这次更新，PickScribe 从「编辑器 + 阅读助手」，长成了一个更像样的**社区工作台**：

- 打开网站先看到一页 **Windows 8 磁贴式起始页** 🧱
- 回帖也有了 AI：**帮你写、帮你润色**，但**绝不自作主张发送** ✍️
- 设置页整个重做，**一个侧边栏管完所有功能** ⚙️
- 收藏夹 Plus 补上了 **导出 / 导入 / 统计**，数据真正搬得走 🗂️

一次更新，四件大事，**v3.3.0** 全部落地 ✅

> 如果你是从 v3.0 直接跳上来的：上一版的「AI 帖子总结 + 提问追问 + 收藏夹 Plus」也一并包含在内。

## 🧱 新增：PICKCAT 起始页浮层

每次**整页打开**站点首页（`/` 或 `/forum`），会先看到一页居中的起始页——像 Windows 8 的开始屏幕，磁贴点哪去哪：

**左侧磁贴**

- **返回社区**（大磁贴）、**发帖**、**搜索**、**消息**、**作品**、**收藏**、**设置**
- 「搜索」直接在当前浮层里展开输入框，回车搜索；也可以随时按 `/` 唤起

**右侧内容区（三个 Tab）**

| Tab | 内容 |
| --- | --- |
| 社区精选 | 直接读取站点首页信息流里已有的帖子，**不发任何额外网络请求** |
| 我的收藏 | 读出收藏夹 Plus 的本地数据，展示最近收藏，一键跳到收藏工作台 |
| 快捷导航 | 六大分类入口 + 作品广场 / 消息中心 / 个人图盘 / 账号设置 + PickScribe 工具 |

配套细节：

- 顶部实时时钟，底栏显示当前版本号
- `Esc` 返回社区、`/` 搜索，离开首页自动收起
- **只认整页加载**：站内 SPA 跳回首页不会反复弹，不打断浏览
- 不喜欢？设置页一个开关关掉，或在浮层底部点「在设置中关闭」

## ✍️ 新增：AI 回帖助手（帖子详情页）

回复框上方的工具行里，多出「**AI 回复 / AI 润色**」两个按钮，点开就是一个独立浮层：

**Tab 一：帮我写**

- 自动读取**帖子标题、正文和已有评论**，生成一条能直接发布的回复
- 语气可选：**赞同 / 提问 / 补充 / 专业 / 轻松**
- 长度可选：**简短（40 字内）/ 适中（60–150 字）/ 详细（150–300 字）**
- 已有评论只作为「讨论氛围参考」，提示词明确要求**不重复别人的观点**、不编造事实

**Tab 二：润色草稿**

按用途分三组，不用在长按钮排里找：

- **改表达**：润色 / 更自然 / 更精炼 / 扩写
- **调语气**：更礼貌 / 更专业 / 更轻松
- **理结构**：分点表达

**安全底线**

- 结果只会「**填入输入框**」「**复制**」「**再生成**」，**永远不会自动发送**
- 填进去之后你还能自己改，确认无误再点站点的发表
- 兼容站点的 `textarea` 与 `contenteditable` 两种回复框

## 🤖 AI 写作助手：快捷指令重新分组

编辑器工具栏里的「AI 写作助手」也顺了一次手：

- 原来 8 个按钮挤成一排，现在按用途分组，**左列固定标签、右侧胶囊**，多行也整齐对齐
- 分组为：**改表达**（润色 / 更自然 / 缩短 / 扩写）、**理结构**（整理成大纲 / 起标题）、**换语言**（译成英文）、**接着写**（续写）
- 想更自由？底部输入自定义要求，`Ctrl + 回车` 直接生成

## 🖥️ AI 总结面板：三种显示尺寸

总结内容短则几十字、长则上千字，这次给了三种看法：

- **标准宽度**：默认限制可读宽度 `760px`，宽屏上不再横跨整行
- **加宽**：一键占满正文宽度，状态会记住，下篇帖子继续沿用
- **全屏**：脱离正文流，居中浮层展示（遮罩 + 背景模糊），`Esc` 或点遮罩退出；退出后**原位归还**，不会把面板弄丢

窄屏（≤820px）自动铺满，不用手动切。全屏时还会锁住页面滚动，避免背景跟着滑。

## ⚙️ 设置页重做：一个侧边栏管完所有功能

原来的设置页是一条长表单，现在改成了左侧分区导航 + 右侧卡片：

| 分区 | 内容 |
| --- | --- |
| 模型与连接 | 服务商预设、Base URL、API Key、模型名、温度、最大 token、测试连接 |
| 提示词与输出 | 系统提示词、用户模板（`{{title}}` `{{author}}` `{{content}}` `{{lang}}` `{{length}}`）、输出语言与长度 |
| 行为 | 触发方式、自动总结最小字数、流式开关、总结面板总开关 |
| 起始页浮层 | 起始页显示开关 |
| 收藏夹 Plus | 收藏行为、取消收藏处理、同步频率、默认视图与排序、主题、站点注入、数据迁移 |
| AI 数据 | 清空总结缓存、导出 / 导入配置 |

其它改进：

- 顶栏常驻「保存 / 测试连接」，右侧有保存状态提示
- **主题三态菜单**：跟随系统 / 亮色 / 暗色，选择即时生效并记住；页面加载前先定主题，**不闪白**
- 密钥依旧只存本机，不上传任何第三方

## 🗂️ 收藏夹 Plus：数据搬得走、状态看得见

在原有分组、标签、备注、检索的基础上，补齐了数据管理：

- **导出 JSON**：完整备份，含分组、标签、备注与站点元数据
- **导出 CSV**：方便丢进表格整理
- **导出 Markdown**：人读版清单，可直接贴进笔记
- **导入合并**：智能合并，完成后告诉你「新增 X 条、更新 Y 条」，不会无脑覆盖
- **清空本地收藏数据** + 本地收藏统计
- 以上都在设置页「收藏夹 Plus」分区，改完**即时生效**，不用点保存

> 站点收藏夹仍是唯一数据来源，插件只在本地附加「分组 / 标签 / 备注」；与站点收藏夹的自动同步会在后续版本接入，当前用导出 / 导入迁移最稳。

## 📌 打包与分发

- 继续采用**单体套件**：一个扩展装下「编辑器 + AI 助手 + 回帖助手 + 起始页 + 收藏夹」，**每项功能单独开关**，一处配置、一处更新
- 发版统一 **ZIP**（`manifest.json` 置于根目录、正斜杠路径），避免 `.crx` 被浏览器拦截
- **权限未变**：仍然只有 `storage` + 可选网络权限（只在你保存 / 测试连接时，针对你填写的域名询问一次）
