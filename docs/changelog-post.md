# 🐱 PickScribe 新版本发布：AI 用量 · 搜索页美化 · 编辑器深色修复 🚀

🗓️ **26-10-30 SP5**

## ✨ 更新要点

这次把 3.4.1 到 3.5.3 的改动合并成一版发布，主要围绕 AI 助手、搜索页和编辑器体验 🧩

- **AI 助手**：三个入口都能看到 Token 用量，生成过程可随时停止 ⏹️
- **搜索页**：改成居中窄栏，带吸顶搜索框与搜索历史 🔍
- **编辑器**：原生工具栏不再重复，原生「全屏 / 预览」按钮彻底隐藏 🛠️
- **站点外观**：鸿蒙字体开关移入设置页，深色模式背景修复 🌗
- **收藏夹 Plus**：模块整体下线，站点收藏功能不受影响 🗑️

---

## 🤖 AI 助手

### Token 用量

- 总结面板、回帖助手、编辑器写作助手底部显示本次调用：`↑输入 ↓输出 · 合计` 📊
- 服务商未返回 usage 时按字符估算，数字前标 `≈`
- 缓存命中的总结显示「缓存命中 · 0 Token」，说明没有重新调用模型
- 设置页新增「AI 数据」累计统计，按模型分列，可一键清空
- 「测试连接」成功后同样显示本次 Token

### 停止生成

三个 AI 入口都加了停止按钮，中断后已经输出的内容会保留，可以继续复制或插入 ⏹️

### 快捷追问

总结面板的「提问」Tab 在空对话时提供三个问题胶囊：核心结论、关键要点、作者依据，点一下直接追问 💬

### 界面统一

- 三个面板改用站点 Nuxt UI 令牌，深浅色主题自动跟随 🎨
- 主色统一为站点红 `#fa322d`，圆角统一为 8px / 6px
- 彩色渐变图标换成站点风格的单色图标，错误提示改用 `--ui-error`

### 回帖入口

- 「AI 回复 / AI 润色」合并为一个「AI」按钮，打开面板后再切「帮我写 / 润色草稿」
- 入口挂到工具行最右侧图标之后，不再压住「分享你的想法喵…」占位文案
- 从帖子列表点进详情页不再需要刷新，路由切换后自动挂载 🧭

---

## 🔍 搜索页美化

- `/search` 改为居中窄栏，隐藏顶栏与左侧筛选栏
- 顶部换成「LOGO + 大搜索框 + 筛选胶囊」，搜索与筛选仍代理站点原有控件 🧲
- 支持吸顶与搜索历史，历史保留条数可配置，可一键清除
- 设置改动即时生效，不用保存

---

## 🧱 编辑器

- **原生工具栏去重**：可视化模式下不再和插件工具栏上下重复，站点重渲染后 600ms 内重新隐藏
- **原生按钮隐藏**：`全屏 / 预览 / 最大化 / fullscreen / preview` 一并隐藏，切回源码或分屏时恢复 🛠️
- **站点外观**：设置页新增独立分区，鸿蒙字体开关从编辑面板迁入，改完当前页面立即生效 🔤
- **界面调整**：去掉卡片底色与描边，选中态改用 accent-soft；3.5.3 修复了这套样式在深色模式下整片发白的问题 🌗

---

## 🗑️ 收藏夹 Plus 下线

- 弹窗分区、设置页分区、帖子页注入和收藏工作台页面全部移除
- 站点本身的收藏功能不受影响；本地的分组 / 标签 / 备注数据不再读写，需要留存的话请用旧版「导出收藏夹」的备份

---
