## 🤖 本次更新（v3.0.0）｜帖子详情页多了个 AI 总结

打开任意帖子详情页，在「作者头像 + 点赞」那条**分隔线的下方**，会出现一张 **AI 总结**卡片：

- 点「**开始总结**」→ AI 读正文，**流式**输出要点，边生成边显示
- 结果可**复制**、**重新总结**（忽略缓存）、**折叠**、**关闭**（本页不再显示）
- 以「帖子 + 模型 + 提示词」为键**缓存**，同一篇命中即秒出，不重复烧 token
- 触发方式可选「**手动点击**」（默认）或「**打开帖子即总结**」
- 输出**语言**（跟随原文 / 简体中文 / English）与**长度**（短 / 中 / 长）都能配
- 面板复用站点设计变量，浅色 / 深色主题自动跟随，入场淡入 `.4s cubic-bezier(.22,1,.36,1)`

> ❌ 不做的事：**不在列表页对多帖批量总结**——省 token，也不打扰你正常刷帖。

配套还做了：**设置页**（提示词模板、温度、最大 token、流式开关……）、**测试连接**一键验活、**清空缓存 / 导出导入配置**、**扩展弹窗**快速切换模型，以及 **🔒 密钥只存本地**（只发往你自己填的接口域名，不上报任何第三方）。

### 🛡️ 权限上的变化

为了让接口地址可自定义，扩展不再完全「零权限」：新增 `storage` 权限、以及**可选**网络权限（安装时不申请，只有你点「保存 / 测试连接」时才针对**你填的那个域名**询问一次）。**编辑器模块 `content.js` 零改动**，AI 走独立命名空间 `pcai`。

> 已装旧版的朋友：更新后在 `chrome://extensions/` 点一下**重新加载**，再去设置页填模型与密钥即可用上。

## 💬 本次新增｜总结会排版了，还能接着问

- **总结结果支持 Markdown 渲染**：标题、列表、加粗、代码块都正常显示，长文要点一眼扫得清
- **面板新增「总结 / 提问」分段 Tab**：读完总结可以直接就这篇帖子**追问**，支持**连续多轮对话**
- 每轮提问都会**带上帖子正文作为依据**，回答更贴着原文，不容易跑偏
- 提问不写缓存，每次都是新问题；输入框回车发送、`Shift + 回车` 换行

> 这版正在收尾，发布后更新扩展即可使用 🐾

### 收藏夹 Plus（另一份 PRD · v0.3）

站点自带收藏夹是一条**平铺列表**：只能按时间看，不能分组、不能检索、不能备注。规划给它补上：

- **P0（43 项）**：分组体系、收藏时归组、浏览检索、标签与备注、批量整理、收藏夹导出 / 导入、入口与呈现、基础设置
- **P1（4 项）**：嵌套分组、智能分组、标签推荐、云同步跨设备
- 数据以**站点收藏夹为唯一来源**，插件只在本地附加「分组 / 标签 / 备注」；同样**归属 PickScribe 扩展**，共用一次安装、一处配置
