## 🤖 本次更新（v3.1.0）

### 一、AI 帖子总结助手

打开任意帖子详情页（`/forum/post/...`），在「作者头像 + 点赞」那条**分隔线的下方**会出现一张 **AI 总结**卡片：

- 点「**开始总结**」→ AI 读正文，**流式**输出要点，边生成边显示
- 结果可**复制**、**重新总结**（忽略缓存）、**折叠**、**关闭**（本页不再显示）
- 以「帖子 + 模型 + 提示词」为键**缓存**，同一篇命中即秒出，不重复烧 token
- 触发方式可选「**手动点击**」（默认）或「**打开帖子即总结**」
- 输出**语言**（跟随原文 / 简体中文 / English）与**长度**（短 / 中 / 长）都能配
- 面板复用站点 `--ui-*` 设计变量，浅色 / 深色主题自动跟随，入场淡入 `.4s cubic-bezier(.22,1,.36,1)`

> ❌ 不做的事：**不在列表页对多帖批量总结**——省 token，也不打扰你正常刷帖。

### 二、总结完还能「接着聊」：提问 Tab + Markdown 渲染

- 面板顶部新增「**总结 / 提问**」分段 Tab：读完总结可以直接就这篇帖子**追问**，支持**连续多轮对话**
- 每轮提问都会**带上帖子正文作为依据**，回答贴着原文走，不容易跑偏；提问不写缓存，每次都是新问题
- 输入框回车发送、`Shift + 回车` 换行，随内容自动长高
- 总结与回答均支持 **Markdown 渲染**：小标题、要点列表、加粗、行内代码、引用、分割线、**表格**都能正常排版，长文要点一眼扫得清

### 三、自动总结更省心：本地字数质检（不花一分 token）

自动模式最怕「一打开就把水贴也总结了」。现在会在**调用模型之前**先做一次**纯本地**的正文质检：

- 去掉空白字符后统计正文字数，低于门槛（默认 **100 字**，可在设置页调整，填 `0` 即不限制）**直接跳过**，不发起任何请求
- 跳过后面板给出提示：「这篇帖子约 N 字，低于自动总结门槛（M 字），已跳过；仍可手动总结。」
- **手动点「开始总结」不受限制**，想总结多短的帖子都行

> 一句话：省 token、少打扰，但主动权始终在你手里。

### 四、内置多家模型，也能自定义任意 OpenAI 兼容接口

设置页（扩展图标 → 打开设置）里内置了这些预设，选了就自动带出接口地址与候选模型名：

| 服务商 | 说明 |
| --- | --- |
| DeepSeek 深度求索 | 按量计费、价格极低，国内直连稳定 |
| 豆包 · 火山方舟 | 新用户赠送免费额度 |
| 通义千问 · 阿里云百炼 | 百炼新用户有免费额度 |
| 月之暗面 Kimi | 长上下文见长 |
| 智谱 GLM | `glm-4-flash` 为免费模型 |
| 硅基流动 SiliconFlow | 提供多款免费模型（模型名需带组织前缀） |
| OpenRouter | 带 `:free` 后缀的模型免费（有速率限制） |
| 本地 Ollama | 本地运行、无需 API Key |
| 自定义 | 任意兼容 `/chat/completions` 的 Base URL |

配套还做了：

- **设置页**：服务商 / 模型 / Base URL / API Key / 温度 / 最大 token / 系统提示词 / 用户模板（支持 `{{title}}` `{{author}}` `{{content}}` `{{lang}}` `{{length}}` 变量）/ 语言 / 长度 / 触发方式 / 自动总结最小字数 / 流式开关 / 启用开关
- **测试连接**：一键验证密钥与模型名是否可用
- **数据管理**：清空总结缓存、导出 / 导入配置
- **扩展弹窗**：分区切换，一屏管理「AI 助手」与「收藏 Plus」
- **🔒 密钥安全**：API Key 只存 `chrome.storage.local`，只发送给你自己配置的接口域名，不上报任何第三方

### 五、全新「收藏夹 Plus」：给站点收藏夹补上分组与检索

站点自带收藏夹只是一条**平铺列表**——只能按时间看，不能分组、不能检索、不能备注。现在补齐了：

**在站内收藏时（不打断浏览）**

- 收藏成功后弹出「**收藏到分组**」浮动条，可直接勾选分组，或**就地新建分组**
- 也可设置为**直接归入最近使用的分组**，或先进「**未分组收集箱**」
- 收藏按钮旁显示「**已归入 N 个分组**」角标，状态一眼可见

**管理台（弹窗「收藏 Plus」分区，或「在标签页中打开」完整工作台）**

- **分组切换条**：全部 / 未分组收集箱 / 各自定义分组，一键切换；支持新建、重命名、删除等分组管理
- **搜索**：标题、作者、备注、标签全字段命中
- **标签筛选** + **仅看失效**（把已下架的收藏挑出来）
- **排序**（时间等）与 **网格 / 列表**两种视图密度
- **多选与批量整理**：批量归组等连续操作
- **详情抽屉**：给单条收藏写备注、打标签、调整归属
- **筛选状态持久化**：上次的分组与筛选条件，下次打开自动恢复

> 数据只保存在本机；**站点收藏夹仍是唯一来源**，插件只在本地附加「分组 / 标签 / 备注」，互不覆盖。

### 六、权限与安装说明的变化

- 新增 `storage` 权限（保存配置与缓存与收藏数据）
- 新增**可选**网络权限：安装时不申请，只有你在设置页点「保存 / 测试连接」时，浏览器才会针对**你填写的那个域名**询问一次
- 编辑器功能、鸿蒙字体行为**均不变**；三个模块（编辑器 `pcr` / AI `pcai` / 收藏夹 `pcf`）各自独立命名空间，互不干扰
- 匹配范围同时覆盖新域名 `pickcat.dao3.fun` 与旧域名 `cdsq.dao3.fun`

> 已装旧版的用户：更新后在 `chrome://extensions/` 点一下**重新加载**即可。
