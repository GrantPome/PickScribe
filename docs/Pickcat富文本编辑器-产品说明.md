# 🐱 Pickcat 富文本可视化编辑器 —— 不会 Markdown 也能优雅发帖

> 一个注入到 Pickcat 帖子编辑页的油猴脚本：把「写 Markdown 源码」变成「像 Word 一样排版」，
> 排版所见即所得，同时和原生 Markdown 源码**双向实时同步**，不改后台、不改提交逻辑，安心用。

---

## 😩 你是不是也遇到过这些

- 想加粗一下，却要记住 `**这样写**`，一不小心就漏了星号。
- 想插张图、放个表格，对着 Markdown 语法一脸懵，只能去翻教程。
- 从 Word / 网页复制内容进来，带了一堆乱七八糟的字体、颜色、背景，排版全乱。
- 好不容易写完，预览才发现层级、列表、链接全错了，来回改到崩溃。

**这个脚本就是为「发帖新手」准备的。** 打开编辑页就能用，零学习成本。

## 🧰 完整适配原有编辑器的全部功能

脚本不是「另起炉灶」，而是把站点原生编辑器能做的**全部**搬到了可视化工具栏里，
点哪个按钮，背后走的就是站点原有的那套逻辑：

- **Kitten 作品分享** —— 一键唤起站点原生作品选择器，上传 / 选图盘逻辑完全一致
- **表情包** —— 直接调用站点原生表情面板，表情库原汁原味
- **图片** —— 复用站点原生图片上传，不再手写 `![]()`
- **表格** —— 弹窗填行列数，一键生成，编辑区可视化增删内容
- **链接** —— 选中文字即可加链接，自动补 `target="_blank"` 安全打开
- **公式** —— 支持行内公式 `$...$` 与块级公式 `$$...$$`，最终由站点 KaTeX 渲染
- **任务列表** —— 待办清单，复选框可在编辑区**直接点击**切换完成状态
- **标题 / 加粗 / 斜体 / 删除线 / 下划线 / 引用 / 代码 / 分割线 / 对齐 / 颜色 / 高亮** —— 全部齐活

> 也就是说：**站点原生编辑器能做的，这里都能做；而且做得更直观。**

## 🚀 怎么用

**第一步：安装脚本**
1. 浏览器安装 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/) 扩展。
2. 新建脚本，把 `legacy/pickcat-rich-editor.user.js` 的内容整段粘贴进去，保存。
3. 打开任意 Pickcat 帖子编辑页，脚本会自动在原生编辑器上方注入可视化面板。

**第二步：三种视图，随心切换**

- **可视化**：默认模式，像 Word 一样直接排版，最适合新手。
- **分屏对照**：左边写、右边看 Markdown 源码，一边编辑一边学语法。
- **Markdown 源码**：给老手用的，切过去就是原生输入框，两边依然实时同步。

**第三步：写完正常提交即可**
提交时脚本会把最新内容写回原生输入框，走的还是站点原来的提交逻辑，放心。

## ❓ 常见问题

**Q：会不会影响网站其他页面？**
A：不会。脚本只匹配帖子编辑页，其他页面完全不注入、不运行。

**Q：提交的内容会不会和以前不一样？**
A：不会。最终提交的仍是标准 Markdown，和站点原生编辑器完全一致，只是帮你把排版过程变简单了。

**Q：粘贴 Word / 网页内容为什么格式变干净了？**
A：这是刻意的。脚本会白名单过滤掉冗余字体、背景、隐藏元素等，只保留标题、加粗、颜色、链接等有效排版，避免排版错乱。

**Q：我不想用了怎么办？**
A：在 Tampermonkey 里禁用或删除脚本，编辑页立刻恢复站点原样，不留任何痕迹。
