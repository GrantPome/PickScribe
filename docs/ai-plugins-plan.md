## 0. 背景与共性

第一份规划（见 [plan.md](./plan.md)）已确定「AI 帖子总结助手」。本辑在其基础上，规划更多 AI 插件，并抽出一套**所有插件共用的 AI 内核**，避免重复造轮子。

### 0.1 实测站点结构汇总（所有插件共用）

| 用途 | 选择器（实测） | 兼容性 |
| --- | --- | --- |
| 帖子列表卡片 | `article[data-slot="root"]` | 首页/列表页 |
| 帖子详情根节点 | `article.relative` | 详情页 |
| 帖子正文 | `.markdown-body` | 详情页 |
| 头像+操作头行（含分隔线） | `div[aria-label="作者与帖子操作"]` | 详情页 |
| 评论输入框 | `textarea.reply-composer-input` | 详情页 |
| 评论列表容器 | `div.post-comment-replies` | 详情页 |
| 操作按钮 | `aria-label="点赞" / "收藏" / "分享帖子"` | 详情页 |
| 用户主页 | `/profile/<uuid>` | 个人页 |
| 发帖编辑页 | `/forum/editor?type=create` | 编辑页 |
| 暗色模式 | `<html class="dark">` + `--ui-*` 变量 | 全站 |
| 页面形态 | Nuxt SPA（`__nuxt`） | 站内跳转不刷新 |

### 0.2 通用工程约束（沿用 PickScribe 经验）

- MV3 content script，匹配 `https://pickcat.dao3.fun/*` + 旧域名 `https://cdsq.dao3.fun/*`。
- **SPA 路由监听**：常驻 watchdog 监听 `location.href`，站内跳转后重新挂载（绝不能只在 `document_idle` 注入一次）。
- **面板存活重建**：站点 Vue 渲染会清除注入节点，需存活检测 + 自动重建（PickScribe v1.1.6 已验证该模式）。
- **选择器集中管理 + 多级降级**，避免站点改版即失效。
- 请求统一走 Service Worker（绕开 CSP/CORS，集中管理 Key）。
- 暗色/亮色自适应，面板动效自然（淡入 ~400ms，`cubic-bezier(0.22,1,0.36,1)`）。

## 2. AI 回帖助手（Smart Reply）

| 项 | 内容 |
| --- | --- |
| **定位** | 基于帖子正文与已有评论，生成一段可以「直接改一改就发」的回复草稿 |
| **触发** | 评论区旁注入「✨ AI 代写」按钮（手动）；也可快捷键 |
| **注入点** | `textarea.reply-composer-input` 上方/旁，按钮填充草稿到输入框 |
| **核心逻辑** | 提取正文 + 前若干条评论（`div.post-comment-replies`）→ 提示词生成草稿 → 填入输入框；可选语气（赞同/提问/补充/幽默）、长度、是否 @作者 |
| **安全边界** | **只填充不自动提交**，用户确认后手动发送，规避垃圾评论风险 |
| **MVP** | 生成 1 段草稿填入输入框 |
| **复杂度** | 中（依赖正文提取，复用总结插件内核） |

## 3. AI 双语翻译（Inline Translate）

| 项 | 内容 |
| --- | --- |
| **定位** | 帖子和评论一键翻译，原文/译文对照显示 |
| **触发** | 头行注入「译」按钮；支持**划词翻译**（选中文本即弹小气泡） |
| **注入点** | 正文 `.markdown-body` 段落下方插入译文块；评论文本下方插入译文 |
| **核心逻辑** | 分段翻译（保留 Markdown 结构，代码块不译）→ 逐段渲染；按「帖子 UUID + 目标语言」缓存 |
| **亮点** | 对照模式（原文浅色 + 译文深色）；可整篇 / 仅首段 / 划词 |
| **MVP** | 整篇中↔英翻译 + 缓存 |
| **复杂度** | 中 |

## 4. AI 发帖写作助手（Compose Copilot）

| 项 | 内容 |
| --- | --- |
| **定位** | 在发帖/编辑页辅助写作：生成大纲、润色、扩写、缩写、Markdown 排版 |
| **触发** | 编辑页工具栏注入「AI 助手」按钮组 |
| **注入点** | `/forum/editor?type=create` 编辑区旁侧边面板 |
| **核心逻辑** | 读取编辑区内容 → 按指令变换 → 写回编辑区；复用 PickScribe 对 `![<uuid>]` 自定义图片引用的处理经验（**不可转义、原样保留**，否则图片丢失） |
| **亮点** | 一键「整理排版 / 加标题 / 扩写要点 / 转口语化」；写作风格预设 |
| **MVP** | 润色 + 排版两个动作 |
| **复杂度** | 中高（涉及编辑器回写，与 PickScribe 经验强相关） |

## 5. AI 速读与「向本帖提问」（TL;DR / Ask）

| 项 | 内容 |
| --- | --- |
| **定位** | 长帖先看 3 行摘要 + 章节大纲，并可对帖子内容追问 |
| **触发** | 详情页头行分隔线下方面板，含「TL;DR / 大纲 / 提问」三个 Tab |
| **注入点** | 同总结插件位置（头行之后、`.markdown-body` 之前） |
| **核心逻辑** | 帖子正文作为上下文（RAG-lite）→ 摘要 + 大纲 + 多轮问答；问答仅基于正文，避免幻觉，回答附原文依据 |
| **MVP** | TL;DR + 章节大纲 |
| **复杂度** | 中高（问答涉及多轮上下文与「仅依据正文」约束） |

> 与「总结助手」高度重叠，建议二者**合并为同一面板的不同 Tab**，减少重复安装。

## 6. AI 内容标签与语义检索（Tag & Search）

| 项 | 内容 |
| --- | --- |
| **定位** | 为帖子自动生成标签；跨帖语义搜索与「相似帖子」推荐 |
| **触发** | 列表卡片（`article[data-slot="root"]`）角落显示 AI 标签；顶部注入搜索框 |
| **注入点** | 列表页卡片 + 全局搜索入口 |
| **核心逻辑** | 抓取列表/帖子文本 → 生成标签 → 本地向量化（浏览器内 `embedding` 或服务端 embedding API）→ 相似度排序 |
| **亮点** | 「找相似帖」「按主题筛选」「相关推荐」 |
| **MVP** | 帖子标签 + 关键词语义搜索（先不做向量，走简单打分） |
| **复杂度** | 高（涉及索引与存储规模、embedding 成本） |
| **风险** | 全站索引 token 成本高，需限定范围与缓存 |

## 8. 共享 AI 内核（关键设计）

所有插件共用一套内核，插件只负责「取内容 / 显示结果」：

```
ai-core/
├─ provider.js      # 服务商抽象（OpenAI 兼容、Ollama、可选 Anthropic/Gemini）
├─ llm-client.js    # fetch + SSE 流式解析
├─ model-router.js  # 按任务/配置选择模型
├─ prompt.js        # 提示词模板（总结/回帖/翻译/润色/问答）
├─ cache.js         # 以「帖子ID+任务+模型+提示词哈希」为键缓存
├─ panel.js / .css  # 通用面板组件（标题栏/流式/折叠/重试/亮暗色）
└─ storage.js       # 配置读写
```

**统一入口**
- **Options 页**：一处管理所有插件的开关、模型、Key、提示词。
- **Popup**：当前页快速开关各功能、切换模型。

**收益**：新增一个 AI 插件 = 写一个「提取器 + 面板挂载点 + 提示词」，其余全部复用。这也符合「分层解耦、便于迭代」的目标。

## 9. 打包与分发决策（需你拍板）

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| A. **单体套件**（一个扩展含全部功能 + 各功能开关） | 一次安装、共享内核、体验统一 | 体积大、发版耦合 |
| B. **独立插件**（每个功能一个扩展，共享内核源码） | 可独立发版、按需安装 | 需多次安装、内核需同步维护 |
| C. **混合**（核心「总结+速读」为套件，其余独立） | 折中 | 略微复杂 |

> 倾向 **A（单体套件）**：一处配置、一处更新，最适合个人站点场景；若未来要上架商店再拆分为 B。

## 12. 通用风险与对策

| 风险 | 对策 |
| --- | --- |
| SPA 站内跳转错过挂载 | 常驻 watchdog + 内容就绪判定 |
| 面板被站点 Vue 渲染清除 | 存活检测 + 自动重建（PickScribe v1.1.6 模式） |
| 站点改版选择器失效 | 选择器集中 + 多级降级 + `aria-label` 语义锚点 |
| 面板被容器裁剪 | 插入为顶级兄弟节点，必要时脱离裁剪层 |
| AI 生成内容被误发/误用 | 回帖只填充不自动发送；画像只做客观描述 |
| Key 泄露 / 数据外传 | 仅存本地、仅发往用户配置域名、不外传 |
| 长文本超上下文 | 自动截断 / 分块 map-reduce |
| token 成本失控 | 缓存优先、按需触发、可设「仅手动」 |
