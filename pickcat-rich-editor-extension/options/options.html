起始页浮层

打开站点首页时展示的一层 Windows 8 风格磁贴起始页。此区改动即时生效。

内容区

功能磁贴

勾选要在起始页显示的磁贴，尺寸可选小 / 宽 / 大，↑ ↓ 调整顺序；也可以直接在起始页拖动磁贴排序。

    内容标签页

    至少保留一个标签页；「默认打开」会随启用项自动校正。

      浮层只读取首页已有内容与本地收藏，不额外请求接口。关闭后不再自动弹出，其他功能不受影响。

      收藏夹 Plus

      为站点收藏补充分组、标签、备注与检索。此区改动即时生效，无需点右上角保存。

      默认行为

      分组、标签与备注只保存在本机，除站点自身请求外不发起外部请求。站点收藏夹自动同步将在后续版本接入，当前可用导出 / 导入迁移数据。

      数据迁移

      搜索页

      站点搜索页的排版、吸顶与搜索记录。此区改动即时生效，无需点右上角保存。

      搜索记录

      只在搜索首屏显示最近搜过的词，点击即可再次搜索；记录保存在本机，不随账号同步。

      站内通知

      后台轮询社区未读消息，通过 Windows 右下角的系统通知弹出。改动即时生效，无需点右上角保存。

      监听站点

      首次开启会静默记录当前未读，之后只弹新增通知；点击通知直达对应帖子，工具栏图标上的红色角标为当前未读数。若 Windows 开启了专注助手 / 勿扰，通知可能被系统拦截。

      AI 功能

      模型连接、生成参数、提示词、触发行为与本地数据统一在此配置。

      模型与连接

      选择服务商，填写模型名与 API Key。全部走 OpenAI 兼容协议。

      生成参数

      提示词与输出

      留空则使用内置提示词。自定义时保留变量占位符即可。

      行为

      控制 AI 总结何时出现，以及是否流式显示。

      AI 数据

      缓存以「帖子 + 模型 + 提示词」为键，命中即秒出；清空后下次打开帖子会重新调用模型。

      输入0
      输出0
      合计0
      请求次数0

      仅统计真实调用，缓存命中不计入；服务商未返回 usage 时按字符估算。

      站点外观

      影响整个站点的显示效果，改动即时生效，无需点右上角保存。

      字体

      字体文件随扩展本地分发，不联网；只覆盖站点的正文与组件字体，代码块、公式仍使用各自的等宽 / 数学字体。关闭后恢复站点原字体。
